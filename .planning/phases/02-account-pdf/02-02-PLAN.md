<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> API auth | credenziali non fidate (email/password) |
| cookie -> sessione | il session_id nel cookie autentica ogni richiesta |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Information Disclosure | password a riposo | mitigate | Argon2id via argon2-cffi (mai passlib, Pitfall 2); password_hash marcato segreto e assente da ogni schema (ASVS V2.4) |
| T-02-04 | Spoofing | session id | mitigate | id ad alta entropia `secrets.token_urlsafe(32)`, scadenza server-side, lookup DB per ogni richiesta (ASVS V3) |
| T-02-05 | Elevation of Privilege | route admin | mitigate | dependency `require_admin` server-side (403), ruolo mai deciso dal client (ASVS V4) — AUTH-04 |
| T-02-06 | Information Disclosure | UserOut | mitigate | schema a campi chiusi, mai model_validate su ORM User (D-13) |
| T-02-07 | Spoofing | session fixation | mitigate | create_session genera SEMPRE un nuovo id (nessun riuso pre-login) |
</threat_model>
