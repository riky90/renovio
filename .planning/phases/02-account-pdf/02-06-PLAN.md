## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> /auth/password-dimenticata | richiesta che potrebbe sondare l'esistenza account |
| link email -> /auth/reimposta-password | token in URL potenzialmente intercettabile/riutilizzabile |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Information Disclosure | user enumeration su reset | mitigate | Risposta identica sempre; nessun ramo osservabile diverso (UI-SPEC D, ASVS V2) |
| T-06-02 | Tampering | token reset manomesso | mitigate | itsdangerous firma HMAC (SECRET_KEY); read ritorna None su BadSignature |
| T-06-03 | Replay | riuso del token entro la scadenza | mitigate | Riga PasswordResetToken con `used`; conferma marca used -> secondo uso 400 |
| T-06-04 | Information Disclosure | link reset a scadenza troppo lunga | mitigate | max_age 3600s (1h); scaduto -> 400 |
| T-06-05 | Denial of Service | flood richieste reset | mitigate | `@limiter.limit("5/minute")` su entrambi gli endpoint |
</threat_model>
