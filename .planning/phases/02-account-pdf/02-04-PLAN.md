<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (JS) -> cookie sessione | il cookie deve restare invisibile a JS |
| frontend origin -> backend origin | richieste cross-origin in dev |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | furto cookie via XSS | mitigate | Cookie httpOnly gestito dal backend; il frontend non legge/scrive mai il token (D-02) |
| T-04-02 | Spoofing | cookie non inviato cross-origin | mitigate | `credentials: "include"` su tutte le fetch auth + CORS allow_credentials gia attivo (Pitfall 4) |
| T-04-03 | Elevation of Privilege | UI mostra stato admin | accept | Nessuna decisione di autorizzazione lato client; il ruolo e solo indicativo nell'header, i controlli sono server-side (Plan 03) |
</threat_model>
