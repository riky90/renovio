## Phase Goal

**Come** admin che tara il catalogo, **voglio** curare domande, opzioni ed effetti dal pannello e da un file Excel, **così che** cambiare una domanda non richieda un deploy.

<objective>
Il file del catalogo torna indietro. Una nuova voce `HANDLER["domande"]` nel registro di Fase
08 — nessuna route nuova, nessun secondo meccanismo — rilegge i cinque fogli scritti dal piano
03 con le regole ereditate (D-01, D-03, D-04, D-09, D-10, D-11, D-12) e quelle di questa fase:
`attiva` si cambia dal file (D-30) ma la guardia D-28 vale anche qui, come scarto descritto e
non come errore che blocca l'import. Il bottone "Carica file" in testa alla pagina apre il
`FlatImportDialog` generico con `risorsa="domande"`.

Purpose: chiude CUR-01 (round-trip) e CUR-02 (colonna assente = non toccato) sul catalogo, e
rende `derivazione_risposta` e `attesa_immobile` curabili senza seed (D-06, D-40).
Output: `services/import_excel/domande.py`, una riga di import nel router, test di import,
bottone Carica.
</objective>
