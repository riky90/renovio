<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin → file `.xlsx` caricato su `POST /admin/upload-listino/preview` | un workbook arbitrario, potenzialmente malformato o costruito ad arte, entra nel parser |
| parser → database curato | 191 voci con 21 `livello` curati a mano: e' il dato che un import sbagliato distrugge |
| preview → confirm | il client re-invia le righe: il server non deve fidarsi che siano le stesse che ha proposto |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-20 | Tampering | import che cancella curatela | mitigate | cella vuota = campo non toccato, cancellazione solo via `#CANCELLA#`; test 3 e 4 verificano entrambi i rami; acceptance criterion con `grep` che nessun `db.delete` esiste nel servizio |
| T-08-21 | Tampering | righe assenti dal file interpretate come eliminazioni | mitigate | D-10: l'import e' solo additivo/aggiornante; `test_import_non_elimina_mai_righe` conta le righe prima e dopo |
