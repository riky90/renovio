<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `GET /api/v1/admin/listini/{id}/export.xlsx` | un client non fidato chiede un file generato dal database; il ruolo dichiarato dal client non conta mai |
| processo backend → file `.xlsx` che esce dal server | il file circola fuori dall'applicazione: una volta scaricato nessun gate lo protegge piu' |
| processo backend → tabella `export_log` | la traccia e' il controllo: se la riga non viene scritta il download diventa invisibile |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Elevation of Privilege | `GET /admin/listini/{id}/export.xlsx` | mitigate | `Depends(require_admin)` sulla funzione di route (mai solo sul router), test che un `role="user"` riceve 403 |
| T-08-02 | Information Disclosure | contenuto del workbook listino | mitigate | il foglio `voci` elenca colonne esplicite e chiuse: `Voce` non ha colonne di margine per costruzione; acceptance criterion con `grep` che `coefficiente_impresa` non compare nel modulo |
