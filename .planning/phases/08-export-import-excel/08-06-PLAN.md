non una seconda strada.

`FlatImportDialog`, bottone "Carica file" su `/admin/coefficienti`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin → workbook caricato su `POST /admin/import-excel/{risorsa}/preview` | file arbitrario, potenzialmente malformato, che descrive i numeri con cui si calcola ogni stima |
| handler di import → `ListinoCategoria.coefficiente_impresa` | il segreto e' scrivibile da questo percorso: un file sbagliato potrebbe azzerarlo |
| path `{risorsa}` → registro degli handler | valore controllato dal client che sceglie quale codice esegue |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
