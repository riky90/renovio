# Phase 1 — UI Design Contract

> Visual and interaction contract for the Stima Free flow (input + result screen, anonymous). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **Language of all UI copy: Italian.** Greenfield project — this document establishes the design system from scratch.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (recommended — to be initialized by planner; project is greenfield, no `components.json` yet) |
| Preset | not applicable yet — planner runs `npx shadcn init` at scaffold time; use "New York" style, base color **Slate**, CSS variables enabled |
| Component library | radix (via shadcn/ui) |
| Icon library | lucide-react |
| Font | Inter (variable) — system-ui fallback stack |

**Rationale.** Renovation cost estimation for Italian homeowners demands a *trustworthy, calm, professional* aesthetic — closer to a bank/insurance quote than a flashy SaaS. Neutral slate surfaces, one confident accent, generous whitespace, large legible numbers. Mobile-first: homeowners will run the estimate on a phone.

**shadcn components in scope for this phase:** `input`, `label`, `button`, `card`, `command` (autocomplete popover), `popover`, `radio-group` (tipo selector), `skeleton` (loading), `alert` (disclaimer/error), `separator`, `badge`. All from the **shadcn official registry** — no third-party registries in Phase 1.

---

## Spacing Scale

8-point scale. Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, currency range dash padding |
| sm | 8px | Compact spacing (label→input, badge padding) |
| md | 16px | Default gap between form fields and inside cards |
| lg | 24px | Card inner padding, gap between category cards |
| xl | 32px | Section breaks (input summary → cards → total) |
| 2xl | 48px | Page top/bottom padding on desktop |
| 3xl | 64px | Hero/landing vertical rhythm on desktop |

**Exceptions:** interactive touch targets (tipo radio cards, buttons, autocomplete rows) have a **minimum height of 44px** for mobile tap accessibility, even when internal padding would compute smaller.

## Typography

Font: **Inter**. Exactly 2 weights: **400 (regular)** and **600 (semibold)**. Exactly 4 roles.
All currency figures use **tabular figures** (`font-variant-numeric: tabular-nums`) so ranges align vertically across the 4 cards.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.4 |
| Heading | 20px | 600 | 1.3 |
| Display | 30px | 600 | 1.2 |

- **Body** — descriptions of the 3 tipi, disclaimer text, helper text, card category coverage notes.
- **Label** — field labels ("Città", "Superficie (m²)", "Tipo di ristrutturazione"), card category titles, CTA button text.
- **Heading** — screen/section titles ("La tua stima", input summary heading), per-card range value.
- **Display** — the prominent overall total range only. On mobile the total range may drop to 24px if it would otherwise wrap awkwardly (allowed exception).

Max sizes on mobile: Display caps at 24–28px to avoid horizontal overflow of long ranges like `€ 60.712 – € 91.068`.

## Color

Single accent (60/30/10). Base color **Slate**. Accent is a confident professional **blue** — trust without construction-cliché orange.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F8FAFC` (slate-50) | Page background, surfaces |
| Secondary (30%) | `#FFFFFF` on `#E2E8F0` borders (slate-200) | Cards, input summary panel, category cards |
| Accent (10%) | `#2563EB` (blue-600) | See reserved list below |
| Destructive | `#DC2626` (red-600) | Validation/error messaging only |

**Text colors (neutral, not counted in the 60/30/10 split):** primary text `#0F172A` (slate-900), secondary/muted text `#64748B` (slate-500), on-accent text `#FFFFFF`.

**Accent (`#2563EB`) reserved exclusively for:**
1. The primary CTA button "Calcola la stima" (input screen) and "Passa a Pro" (result screen — the single primary action there).
2. The overall-total emphasis panel (accent-tinted background `#EFF6FF` blue-50 + accent left border, accent-colored total figure).
3. Selected state of the tipo radio card (accent ring/border + light accent fill).
4. Autocomplete active/highlighted row and input focus ring.
5. Text links inline in disclaimers.

Accent is **never** applied to all four category cards, all buttons, or decorative surfaces. Secondary CTAs ("Contatta un professionista", "Scarica PDF", "Salva / crea account") use the neutral/outline button variant, not accent.

**Disclaimer/info tone** (fallback listino notice) uses an amber informational treatment — background `#FFFBEB` (amber-50), border `#FCD34D` (amber-300), icon/text `#B45309` (amber-700). This is a semantic info color, distinct from the accent and from destructive; it is the only additional semantic hue and is used solely for the transparency disclaimer.

**Contrast:** all text/background pairs meet WCAG AA (blue-600 on white = 4.5:1+; slate-900 on slate-50 passes; amber-700 on amber-50 passes for the disclaimer).

## Copywriting Contract

All copy in Italian. Currency formatted Italian-style: thousands separator `.`, symbol before amount, ranges as `€ 34.136 – € 51.204` (en-dash with spaces).

| Element | Copy |
|---------|------|
| Primary CTA (input) | **Calcola la stima** |
| Primary CTA (result) | **Passa a Pro** (soft-wall; opens "in arrivo" info for Phase 1) |
| Secondary CTAs (result) | Contatta un professionista · Scarica PDF · Salva / crea account |
| Empty state heading | *(no true empty state — the input form is the landing)* Inserisci i dati per ottenere la tua stima gratuita |
| Empty state body | Bastano tre informazioni: città, superficie in m² e tipo di ristrutturazione. La stima è gratuita e non richiede registrazione. |
| Error state | Non siamo riusciti a calcolare la stima. Controlla i dati inseriti e riprova. Se il problema persiste, riprova tra qualche istante. |
| Field validation — mq | Inserisci una superficie valida (numero maggiore di 0). |
| Field validation — città | Inserisci la città dell'immobile. |
| Field validation — tipo | Seleziona il tipo di ristrutturazione. |
| Fallback disclaimer | Stima basata sul listino di **Reggio Emilia**, non ancora tarata su **{città}**. I valori sono indicativi e da confermare con un sopralluogo. |
| Range reassurance (near total) | Stima pre-sopralluogo. L'importo definitivo dipende dallo stato dell'immobile e dai materiali scelti. |
| IVA note | Totale IVA inclusa. Comprende i costi extra (sicurezza e pratiche amministrative). |
| Soft-wall CTA feedback | Disponibile a breve. Questa funzione arriverà nelle prossime versioni. |

**Destructive actions in Phase 1:** none. There is no login, no saved data, no delete/reset-with-consequence action in this phase. → Destructive confirmation row not applicable. (The color token is declared for validation errors only.)

**Tone rules:** second person singular ("tu"), warm but factual, never over-promise precision (always frame output as *stima* / *indicativa*). Never display or hint at impresa price/coefficient in any string.

## Screen & Component Contracts

Beyond the token tables, the following component contracts are binding for the executor.

### A. Input flow (single screen, progressive, mobile-first)

Layout: single centered column, `max-width: 480px` on mobile through tablet, `max-width: 640px` on desktop, generous vertical spacing (`xl` between fields groups). Three inputs stacked in order, then the primary CTA.

1. **Città** — free-text input with autocomplete (shadcn `command` inside a `popover`, or `input` + suggestions list).
   - Label "Città", placeholder "Es. Reggio Emilia".
   - Suggestions appear after ≥2 characters; active row uses accent highlight; keyboard navigable (arrow/enter).
   - User may type any city and submit even without selecting a suggestion (free text — per D-06).
2. **Superficie (m²)** — numeric input.
   - Label "Superficie (m²)", `inputmode="numeric"`, placeholder "Es. 85", trailing unit adornment "m²".
   - Min 1; reject non-numeric; show mq validation copy inline below field on blur/submit.
3. **Tipo di ristrutturazione** — 3 selectable cards (radio-group), stacked on mobile, 3-across on desktop ≥640px.
   - Each card: title (Label weight) + one-line description (Body, muted). Descriptions (from D-02, condensed for UI):
     - **Leggera** — Tinteggiature, nuovi pavimenti e sanitari, piccole opere.
     - **Moderata** — Rifacimento bagno/cucina, impianti parziali, alcuni serramenti.
     - **Totale** — Demolizioni diffuse, tutti gli impianti, pavimenti e serramenti nuovi.
   - Selected state: accent border + accent ring + light accent fill; unselected: slate-200 border on white. Min 44px height.
4. **Primary CTA** — full-width accent button "Calcola la stima". Disabled (muted, non-accent) until all three inputs are valid.

### B. Result screen

Vertical stack, same column width constraints, `xl` gaps between the four zones:

1. **Riepilogo input** (top) — compact panel (secondary surface) showing chosen città · mq · tipo as three inline pills/badges, with an "Modifica" text-link (neutral) to return to the form.
2. **Fallback disclaimer** (conditional) — rendered *only* when città ≠ Reggio Emilia, directly under the summary, using the amber info `alert`. Uses the fallback disclaimer copy with the entered città interpolated.
3. **4 category cards** — one card per category (Edile, Finiture, Serramenti/Porte, Prodotti), in that order.
   - Grid: 1 column on mobile, 2×2 on tablet/desktop (≥640px), gap `lg`.
   - Each card (white surface, slate-200 border, `lg` padding): category title (Label) + optional one-line "cosa copre" note (Body muted, from seed doc) + the category **range** as `€ min – € max` in Heading size, tabular figures. **No accent on category cards** — they are neutral; only the total is emphasized.
   - Each card range is IVA-inclusive for that category (per EST-03). Never show a single number.
4. **Totale complessivo** (prominent) — the emphasis panel: accent-tinted background (blue-50), accent left border, "Totale stimato (IVA inclusa)" Label + the overall range in **Display** size, accent-colored, tabular figures. Below it, the IVA note (Body muted) and range reassurance line.
5. **CTA cluster** (bottom) — primary "Passa a Pro" (accent) prominent; secondary row "Contatta un professionista", "Scarica PDF", "Salva / crea account" as outline/neutral buttons. On mobile stack full-width; on desktop primary is emphasized and secondaries wrap. All four are soft-wall in Phase 1 → clicking shows the "Disponibile a breve" feedback (toast or inline note), no navigation.

**Domain guard (binding):** no view, tooltip, data attribute, or network payload consumed by this screen may contain the impresa price or coefficient (0.65/0.6/0.55/0.5). Only client range values reach the browser (EST-05 / CLAUDE.md rule 1).

### C. States

| State | Treatment |
|-------|-----------|
| Loading (calculating) | Replace result zones with `skeleton` placeholders matching the 4-card + total layout; keep input summary visible. Sub-second expected, but always render skeletons for perceived stability. |
| Error (calc failed) | `alert` (destructive tone) with the error-state copy + a "Riprova" button that re-submits. |
| Empty | Not applicable — the input form is the entry point; before submission the user sees the form with the empty-state helper copy, not a blank result. |
| Fallback (no listino for città) | Amber disclaimer alert shown above the cards (see B.2). Estimate still renders fully. |
| No results / zero | Not expected (every valid input yields a range); if a category multiplier ≈ 0 (e.g. Edile in Leggera), still render the card with its computed low range, never hide it. |

### D. Responsive behavior (mobile-first)

- **Base (≤639px):** single column, full-width fields and cards, tipo cards stacked, CTAs full-width stacked. Page horizontal padding `md` (16px).
- **Tablet (640–1023px):** column max 640px centered; tipo 3-across; category cards 2×2; page padding `lg`.
- **Desktop (≥1024px):** same centered column (this is a focused single-task tool, not a dashboard — no sidebar). Page vertical padding `2xl`.
- Total emphasis panel remains full column width at all breakpoints; Display size steps down on mobile per Typography note.

## Open Questions (non-blocking — reasonable defaults set above)

1. **Accent hue** — defaulted to blue-600 (trust). If brand identity later favors a construction-warm tone, an alternative is teal-700 (`#0F766E`). Either keeps the single-accent 60/30/10 discipline; not blocking Phase 1.
2. **Exact IVA aliquota on Serramenti/Porte** — 22% provisional (D-12). UI simply renders whatever the engine returns; no design impact, but the per-category card must not hardcode a rate.
3. **Currency locale rendering** — defaulted to `it-IT` (`Intl.NumberFormat('it-IT', {style:'currency', currency:'EUR', maximumFractionDigits:0})`). Rounding of range bounds (to nearest €? nearest €100?) is an engine/planner decision; UI aligns figures with tabular-nums regardless.
4. **Autocomplete data source** — Phase 1 has only Reggio Emilia as a real listino; the autocomplete may suggest from a static Italian city list or accept free text with no suggestions. Either satisfies D-06; planner decides. Not a visual contract concern.
