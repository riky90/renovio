Schema-target dettaglio (03-PATTERNS.md — design vincolato da D-02/D-05, codice nullable per B/C/D):
```python
class Sottocategoria(Base):  # __tablename__ = "sottocategoria"
    id PK; listino_id FK->listino.id; categoria_code FK->categoria.code
    codice: str | None (String(16), nullable)  # A.1..A.11 per A-EDILE, None per B/C/D
    nome: str (String(200)); famiglia: str (String(16))  # 'gerarchica' | 'catalogo'
    ordine: int

class Voce(Base):  # __tablename__ = "voce"
    id PK; sottocategoria_id FK->sottocategoria.id
    codice: str | None (String(16)); descrizione: str (String(300))
    um: str (String(16))  # mq | cad | ml | ac
    prezzo_unitario_cliente: Decimal (Numeric(12,2))
    # NESSUNA colonna coefficiente_impresa/prezzo_impresa

class CoefficienteQuantitaVoce(Base):  # __tablename__ = "coefficiente_qta_voce"
    __table_args__ = UniqueConstraint("voce_id", "tipo_code")
    id PK; voce_id FK->voce.id; tipo_code FK->tipo_ristrutturazione.code
    coefficiente_qta_per_mq: Decimal | None (Numeric(8,4))
    domanda_mirata_key: str | None (String(32))  # 'bagni'|'porte'|'condizionatori'
    default_conteggio: int | None
```
